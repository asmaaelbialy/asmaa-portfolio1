# Asmaa Mohamed | AI & Data Engineering Portfolio 🚀

موقع شخصي وبورتفوليو بروفيشنال للمهندسة **أسماء محمد سعد الله (Asmaa Mohamed Sadallah)**، متخصص في **الذكاء الاصطناعي وهندسة البيانات (AI & Data Engineering)** ومجهز للنشر المباشر على **GitHub Pages**.

---

## 🌟 المميزات والمحتوى الجديد (What's New)

1. **صور وبنرات احترافية لكل المشاريع (Project Mockups)**:
   - تم تصميم واجهات تفاعلية SVG عالية الدقة (Vector Dashboards) داخل مجلد `assets/images/`:
     - `bus-system.svg`: نظام حافلات جامعة الدلتا الذكي وتقليل زمن المسار بنسبة 20%.
     - `bio-age-ml.svg`: نموذج تقدير العمر البيولوجي بالذكاء الاصطناعي وتعلم الآلة.
     - `data-pipeline.svg`: خطوط معالجة وتدفق البيانات المؤتمتة (ETL) في مبادرة رواد مصر الرقمية (DEPI).
     - `student-system.svg`: نظام إدارة الطلاب بلغة الجافا وقواعد بيانات MySQL.
2. **تصميم تقني عصري (Modern Dark Glassmorphism)**:
   - ألوان السيان النيون والأزرق التقني، وتأثيرات زجاجية مع خطوط Google عصرية (`Poppins` و `JetBrains Mono`).
3. **تفاعلات ذكية**:
   - تأثير الكتابة التلقائية (Typewriter Effect).
   - فلترة المشاريع حسب المجال (AI & Machine Learning, Data Engineering, Software & SQL).
   - نافذة تفاصيل منبثقة (Project Modal Lightbox) عند النقر على أي مشروع لعرض التفاصيل المعمارية.
   - نسخ البريد ورقم الهاتف بنقرة واحدة مع إشعار Toast.
   - نموذج مراسلة مباشر وزر العودة لأعلى الصفحة.
4. **تضمين السيرة الذاتية بالكامل**:
   - تدريب مايكروسوفت (DEPI).
   - دراسة الذكاء الاصطناعي في جامعة الدلتا والمشاركة في الفريق الطلابي.
   - الشهادات المعتمدة من Udemy, BUE, Palo Alto Networks, NTI.

## 🚀 طريقة رفع التحديثات إلى GitHub وتحديث موقعك المباشر

الموقع الحالي مربوط على مستودعك: `https://github.com/asmaaelbialy/asmaa-portfolio`

### الطريقة 1: عبر سطر الأوامر (Git Bash أو Terminal)

إذا كان المستودع موجوداً على جهازك:
```bash
# 1. انسخي الملفات الجديدة إلى مجلد المستودع المحلي
# 2. قومي بتنفيذ الأوامر التالية:
git add .
git commit -m "Update portfolio: modern UI, project mockups, interactive filters and CV data"
git push origin main
```

### الطريقة 2: عبر موقع GitHub مباشرة في المتصفح

1. ادخلي إلى رابط مستودعك: [https://github.com/asmaaelbialy/asmaa-portfolio](https://github.com/asmaaelbialy/asmaa-portfolio)
2. اسحبي وأفلتي ملفات:
   - `index.html`
   - `style.css`
   - `script.js`
   - مجلد `assets` بالكامل
3. اضغطي على **Commit changes**.
4. خلال دقيقة واحدة، سيتم تحديث موقعك الحي تلقائياً على الرابط:
   👉 **[https://asmaaelbialy.github.io/asmaa-portfolio/](https://asmaaelbialy.github.io/asmaa-portfolio/)**

## 💡 تخصيص الصور الشخصية أو صور المشاريع

- **صورتك الشخصية**: الموقع يبحث تلقائياً عن صورتك المسماة `WhatsApp Image 2026-09-20 at 8.44.59 PM.jpeg` بجانب ملف `index.html`. إن وُجدت ستظهر فوراً في الدائرة المضيئة، وإن لم تكن موجودة سيظهر بديل تقني رائع `assets/images/avatar.svg`.
- **صور المشاريع**: إذا كان لديكِ لقطات شاشة (Screenshots) حقيقية ترغبين بوضعها مستقبلاً، يمكنكِ استبدال ملفات الـ `.svg` بملفات صور عادية (PNG أو JPG) وتعديل مسار `src` في ملف `index.html`.
